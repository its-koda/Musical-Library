# 🎵 Sistema Musical — Front-End

Este repositório contém a interface web (Front-End) de um **Sistema de Biblioteca Musical**. O projeto foi estruturado em HTML5 e CSS3, com formulários prontos para receber integração back-end (PHP/Banco de Dados).

---

## 📄 Estrutura das Páginas

| Arquivo | Descrição |
| :--- | :--- |
| `login.html` | Tela de autenticação de usuários com campos de login, senha e validação básica HTML5. |
| `index.html` | Painel principal (Dashboard) com menu de navegação e atalhos rápidos para as demais seções. |
| `cadastro_artista.html` | Formulário para cadastro de novos artistas (com envio de foto) e tabela de listagem/gerenciamento de artistas existentes. |
| `cadastro_musica.html` | Formulário dedicado ao cadastro e inclusão de novas músicas no sistema. |
| `listagem_musicas.html` | Biblioteca musical com busca geral, filtros por artista/gênero, listagem em tabela e links para reprodução no YouTube. |

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica das páginas, formulários e elementos visuais.
- **CSS3 (`style.css` / `styles.css`):** Estilização global com suporte a layouts responsivos em Flexbox e CSS Grid.

---

## 🚀 Como Executar

1. Baixe ou clone os arquivos do repositório para o seu computador.
2. Certifique-se de que todas as páginas estejam na mesma pasta junto com o arquivo de estilo `style.css`.
3. Abra o arquivo `login.html` em qualquer navegador web moderno para navegar pelo sistema.
